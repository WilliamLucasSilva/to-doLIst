# To-Do List

A ideia é criar uma todo-list simples que subdivide as tarefas em pastas e conta o progresso das pastas com um visor de porcentagem.

## Objetivo

Gostaria de "Gameficar" minhas responsabilidades diárias

## Tecnologias

- Js, Html, Css
- Node.js
